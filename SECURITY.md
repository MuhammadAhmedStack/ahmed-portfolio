# Security Policy

## Reporting Security Issues

If you discover a potential security vulnerability or sensitive information disclosure in this repository, please do not disclose it publicly via an issue or pull request.

Instead, please report it privately:

- **LinkedIn**: [Muhammad Ahmed](https://www.linkedin.com/in/muhammadahmedstack/)
- **GitHub**: Open a private advisory via GitHub's [Security Advisories](https://github.com) feature once published.

Please include:
- A description of the vulnerability.
- Steps to reproduce or proof of concept.
- Potential impact.

Thank you for helping keep this project secure.
